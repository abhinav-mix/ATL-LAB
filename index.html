Accident Alert System

A multi-layered, AI + sensor fusion safety platform that detects driver drowsiness and crashes — then triggers a fully automated emergency response without any human input.

AI Drowsiness Detection (EAR)

The app uses Google ML Kit Face Mesh to track 468 facial landmarks in real-time at 30 FPS. It constantly computes the Eye Aspect Ratio (EAR) — the ratio of eye height to width. When EAR drops below 0.25 for ≥ 2 seconds, micro-sleep is confirmed and an alarm is blasted instantly.

ML Kit Face Mesh EAR < 0.25 Threshold 30 FPS Processing

IMU Crash Detection (Accelerometer + Gyroscope)

The phone's accelerometer monitors all 3 axes (X, Y, Z) for sudden G-force spikes. A crash is detected when the net acceleration exceeds 2.5G. The gyroscope simultaneously checks for abnormal vehicle roll/pitch angles. Both sensors must agree before an emergency is triggered — eliminating false alarms from speed bumps.

Accelerometer XYZ Gyroscope 3-Axis 2.5G Threshold Dual Confirmation

Configurable Safety Countdown

After a crash is detected, a customizable countdown (10–30 seconds) begins with a loud alarm. The driver can cancel it if the detection was a false positive. If nobody cancels it, the system assumes the driver is incapacitated and automatically escalates to the full SOS protocol.

10–30s Configurable Driver Can Cancel Auto-Escalation

Automated Emergency Call + Loudspeaker Broadcast

The app automatically dials the pre-configured emergency contact using Android's telephony API — no user interaction needed. Simultaneously, it plays a custom SOS audio message on the device loudspeaker at maximum volume, identifying the driver and their location to anyone nearby.

Auto Phone Call Loudspeaker SOS Audio No Input Required

GPS SMS Alert to All Emergency Contacts

Simultaneously with the call, the app sends an automated SMS to all registered emergency contacts. The message includes the driver's name, a live Google Maps link with GPS coordinates, the crash timestamp, and the detected impact magnitude — so responders know exactly where to go.

Multi-Contact SMS Live GPS Link Google Maps URL Impact Data

Smart Dashcam (Pre-Crash Buffer)

The app continuously records a rolling 30-second video buffer using the front camera. At the moment of crash detection, the last 30 seconds of footage is saved to local storage automatically. This pre-crash video serves as critical accident evidence for police and insurance claims.

Utilizes on-device AI to map facial landmarks in real-time. By continuously calculating the Eye Aspect Ratio (EAR), the app detects micro-sleeps and triggers instant auditory alerts before an accident occurs.

IMU Crash Detection

Smart Waste Hub

An IoT-powered intelligent waste management network — every bin is smart, connected, and self-reporting.

Ultrasonic Fill-Level Sensing

Each bin has an HC-SR04 ultrasonic sensor mounted inside the lid. It continuously measures the distance to the waste surface and converts it into a fill percentage. Readings are taken every 5 seconds.

HC-SR04 Sensor 0–100% Fill Level 5s Interval

MQTT Telemetry Broadcast

The onboard ESP8266 / NodeMCU publishes sensor data over Wi-Fi to a central MQTT broker. Each packet includes the bin ID, zone ID, fill %, GPS coordinates, battery voltage, and a timestamp. Data is received instantly by the dashboard.

ESP8266 Wi-Fi MQTT Protocol Real-time Push

Threshold Alerts & Auto-Dispatch

When any bin crosses 85% fill level, the system automatically generates a dispatch alert. The AI route optimizer recalculates the shortest collection route across all critical bins and sends a notification to the municipal vehicle driver's app.

85% Threshold Alert AI Route Optimizer Push Notification

GPS Zone Mapping

Every bin is registered with a GPS coordinate and zone label in the central database. The live map view on the dashboard colour-codes bins by status — Green (OK), Orange (Warning), Red (Critical).

GPS Geo-tagging Zone Clusters Live Map View

Analytics Dashboard & History

All telemetry is logged to a time-series database. The web dashboard shows fill trends, peak overflow times, collection frequency, and per-zone waste generation heatmaps — enabling smarter city planning and waste reduction.

Time-Series DB Heatmaps Collection History
